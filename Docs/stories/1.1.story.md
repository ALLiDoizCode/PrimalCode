[Source: docs/architecture/coding-standards.md]
- **Type Safety**: All components must have TypeScript interfaces
- **Error Handling**: Every MCP tool must implement comprehensive error handling with user-friendly messages
- **Natural Language**: All MCP tool responses must be engaging, narrative-driven descriptions
- **Naming Conventions**: 
  - Tools: snake_case (e.g., `observe_ecosystem`)
  - Functions: camelCase (e.g., `generateNarrative`)
  - Types: PascalCase (e.g., `MonsterState`)
  - Constants: UPPER_SNAKE_CASE (e.g., `MAX_INFLUENCE_POINTS`)
